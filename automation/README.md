# 每天自动生成文章 —— 使用说明（新手版）

这套东西能做到：**你每天往 `idea.txt` 写一句灵感 → 电脑定时自动生成一篇排版好的文章草稿 → 你审核满意后再发布。**

> 注意：它生成的是**草稿文件**（存到 `output/` 文件夹），不会自动发布。发布由你手动完成，更安全。

---

## 一、先准备好（只需一次）

1. 确认本机已装好 **Node.js、Claude Code**，并且 `baoyu-skills` 已安装、能正常用（参考你之前跑通的步骤）。
2. 确认你的**代理软件**能开着、并且是“全局模式”。
3. 打开 `automation/run-daily.ps1`，把里面的代理端口 `15236` 改成**你自己代理软件的端口**（如果不是 15236 的话）。

---

## 二、先手动跑一次（确认能用）

1. 在 `automation/idea.txt` 里写上今天想写的一句话（例如：`早起的三个好处`）。
2. 打开 PowerShell，运行（把路径换成你电脑上的实际路径）：
   ```
   powershell -ExecutionPolicy Bypass -File "C:\你的路径\media_bot\automation\run-daily.ps1"
   ```
3. 跑完后，去 `output/` 文件夹看有没有生成 `.md` 和 `.html` 文件。
   - 有 → 成功 ✅，进入第三步设置定时。
   - 报错 → 把报错截图发出来排查。

---

## 三、设成每天自动跑（Windows 任务计划程序）

1. 按 `Win` 键，搜索并打开 **“任务计划程序”**。
2. 右侧点 **“创建基本任务”**。
3. 名称随便填，例如 `每日自动写文章`，下一步。
4. 触发器选 **“每天”**，设一个时间（例如早上 8:00），下一步。
5. 操作选 **“启动程序”**，下一步。
6. 填写：
   - **程序或脚本**：`powershell`
   - **添加参数**：
     ```
     -ExecutionPolicy Bypass -File "C:\你的路径\media_bot\automation\run-daily.ps1"
     ```
7. 完成。

> ⚠️ 定时任务跑的时候，**代理软件必须开着**（否则连不上 Claude）。建议把代理软件也设成开机自启。

---

## 四、以后每天你只需要做一件事

每天往 `automation/idea.txt` 里写**一句灵感**（覆盖掉旧的那句），剩下的电脑会自动搞定。
第二天早上去 `output/` 文件夹，看到的就是排好版的文章草稿，审核满意后复制到公众号发布即可。

---

## 五、想手动来一篇（不等定时）

在 Claude Code 交互界面里直接输入（斜杠命令，后面跟灵感）：
```
/daily-article 你的灵感
```
就会立刻生成一篇。
